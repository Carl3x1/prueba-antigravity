#  Prueba Antigravity

##  Descripción general
El proyecto consiste en una landing page para el videojuego *Need for Speed: Rivals*.  
Su objetivo es presentar información visual atractiva sobre el juego, incluyendo secciones informativas, diseño responsivo e interactividad básica.
